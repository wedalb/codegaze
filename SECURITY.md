# Security and research data

The plugin serves code only after Start sharing, on the loopback interface, with a random pairing key. Keep this key private. USB forwarding deliberately grants the connected headset access to that loopback service. Stop sharing and remove forwarding when finished.

Exports contain source snippets, paths and participant labels. Use anonymous study IDs and keep real datasets out of public issues and commits. There is no analytics or automatic cloud upload.

Please report a security issue privately through GitHub's security reporting facility if enabled, or contact the repository owner through their GitHub profile without including exploit details or participant data in a public issue.
